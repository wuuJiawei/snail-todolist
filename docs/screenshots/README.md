## 添加新截图

如需添加更多截图：

1. **命名规范**：`snailtodo-screenshot-{number}.png`
2. **推荐尺寸**：1920x1080 或更高
3. **格式**：PNG（支持透明背景）
4. **内容建议**：
   - 展示核心功能
   - 使用深色或浅色主题
   - 包含适量示例数据
   - 保持界面整洁美观

## 截图工具

推荐使用以下工具：
- **macOS**: Cmd + Shift + 4
- **Windows**: Win + Shift + S
- **Linux**: Screenshot 工具
- **浏览器**: F12 开发者工具 → Device Toolbar → 截图
